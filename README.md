# LIME Predictions

Research project exploring **model explainability** on the classic Iris classification task.

The pipeline trains classifiers on small Iris dataset splits, evaluates a held-out test row in each split, and uses **[LIME](https://github.com/marcotcr/lime)** (*Local Interpretable Model-agnostic Explanations*) to visualize which features pushed incorrect predictions toward the wrong class.

Primary model: **XGBoost**. Baseline comparison: **Logistic Regression**.

---

## Project goals

1. Measure how often XGBoost / Logistic Regression misclassify a held-out Iris sample across many small balanced splits.
2. Rank feature importance across those runs.
3. Generate LIME plots only for **incorrect** predictions, so failed cases are easy to inspect.
4. Optionally drop features (for example `SepalWidthCm`) to study how feature ablation changes accuracy and explanations.

## Method (short)

For each dataset in a processed JSON file:

| Step | Detail |
|------|--------|
| Features | `SepalLengthCm`, `SepalWidthCm`, `PetalLengthCm`, `PetalWidthCm` (any listed features can be dropped) |
| Label | `Species` → encoded with `LabelEncoder` |
| Train / test | Train on all rows except the last; test on the last row |
| Models | `XGBClassifier` or `LogisticRegression` |
| Explain | On misclassifications, fit `LimeTabularExplainer` and save a contribution bar chart |

This leave-one-out-style holdout per split is intentional for local explanation work: each run produces one concrete prediction you can inspect with LIME.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Run all commands from the **repository root**.

---

## Usage

### 1. (Optional) Rebuild dataset splits

```bash
python src/build_datasets.py \
  --num-datasets 15 \
  --samples-per-species 10 \
  --output data/processed/iris_datasets_15.json
```

### 2. Run XGBoost + LIME (default research path)

```bash
python src/xgb_lime_analysis.py
```

Useful flags:

```bash
# Keep all features
python src/xgb_lime_analysis.py --drop-features

# Drop multiple features
python src/xgb_lime_analysis.py --drop-features SepalWidthCm SepalLengthCm

# Use a different JSON split file
python src/xgb_lime_analysis.py --json data/processed/iris_datasets_10.json

# Preserve existing plots instead of clearing outputs/xgb/lime_plots
python src/xgb_lime_analysis.py --keep-old-plots
```

### 3. Run Logistic Regression baseline

```bash
python src/lr_lime_analysis.py
```

Plots are written to `outputs/lr/lime_plots/`.

---

## Outputs

- **Console:** average accuracy across splits and mean feature importances.
- **Plots:** one PNG per misclassified dataset, named like `dataset_3_lime.png`.
  - Green bars: features that supported the predicted class.
  - Red bars: features that opposed the predicted class.

Example XGBoost plots from a prior run are already under `outputs/xgb/lime_plots/`.

---

## Notes / limitations

- Splits are small by design; metrics are for interpretability experiments, not production benchmarking.
- LIME explanations are local to one instance and one model fit — they are not global causal claims.
- `outputs/lr/legacy_dual_plots/` preserves an earlier dual-overlay visualization style and is not regenerated by the current scripts.
